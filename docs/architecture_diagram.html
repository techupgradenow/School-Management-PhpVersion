3. Multi-Tenant Data Isolation

CRITICAL: Every Query Must Include school_id

-- WRONG (Data leakage!)
SELECT * FROM students;

-- CORRECT (Isolated by school)
SELECT * FROM students WHERE school_id = 'SCH001';

-- CORRECT (With JOIN)
SELECT s.*, c.name as class_name
FROM students s
JOIN classes c ON s.class_id = c.id AND s.school_id = c.school_id
WHERE s.school_id = 'SCH001';

5. Correct Data Flow Example

STUDENT DETAIL PAGE - DATA FLOW
================================

User clicks student "John" (ID: 123) in student-detail.html
                    |
                    v
Frontend: $.ajax({ url: '/students.php?action=single&id=123' })
                    |
                    v
API Layer: students.php receives request
                    |
                    v
Service Layer: StudentService->getById(123)
    |
    |-- Calls: StudentRepository->findById(123)
    |       --> SELECT * FROM students WHERE id=123 AND school_id='SCH001'
    |
    |-- Calls: StudentRepository->getParents(123)
    |       --> SELECT * FROM student_parents WHERE student_id=123 AND school_id='SCH001'
    |
    |-- Calls: StudentRepository->getMedical(123)
    |       --> SELECT * FROM student_medical WHERE student_id=123 AND school_id='SCH001'
    |
    |-- Calls: StudentRepository->getDocuments(123)
            --> SELECT * FROM student_documents WHERE student_id=123 AND school_id='SCH001'
                    |
                    v
Response JSON:
{
    "success": true,
    "data": {
        "id": 123,
        "name": "John Doe",
        "class": "Class 10",
        "parents": [...],      // FROM student_parents
        "medical": {...},      // FROM student_medical
        "documents": [...]     // FROM student_documents
    }
}
                    |
                    v
Frontend renders data in correct sections
